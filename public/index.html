    Conexión con GHL

    Para enviar las propuestas desde tu cuenta de GoHighLevel con seguimiento de apertura.

    Comprobando…

    GHL › Ajustes › Integraciones privadas › Crear (permisos: contactos, conversaciones y mensajes, oportunidades, medios).

    Es el código que sale en la dirección de GHL después de /location/.

    La llave se guarda cifrada en el servidor y no vuelve a mostrarse.

    Conexión con Holded

    Para crear el cliente y las facturas de cada propuesta directamente en Holded.

    Comprobando…

    Holded › Configuración › API › Generar nueva clave, con permisos de contactos (leer y escribir), facturas de venta (escribir) e impuestos (leer).

    Se guarda cifrada en el servidor y no vuelve a mostrarse.
